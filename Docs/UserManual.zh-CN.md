# S33D 使用指南

**退出确认提示：**首次在工作区双击/三击退出工具前，会显示当前工具名称和“当前状态将会保留”的说明。选择“确定”才应用、完成并执行原来的选面/选对象；选择“取消”或按 Esc 留在当前工具。勾选“不再显示”并确定后会记住偏好；未勾选会继续提示。在“设置 > 重新启用所有隐藏提示”可恢复此提示和首次使用提示，不改变其他设置。普通空闲选面/选对象不弹窗。

**退出工具并选择：**三维工作区双击或三击会先将当前有效状态应用并完成（Applied and Done），收起工具菜单，再选择光标下的面或整个对象。普通退出和正常切换工具也提交最新参数；已应用的阵列及相对变换不会重复执行。无效参数或建模失败会保留编辑状态并提示原因；后台计算完成后再退出。明确标注“取消”的操作仍会取消草稿。草图正在逐点画线/圆弧等、Draw 3D 正在指定基点/尺寸时，连续点击用于构造几何，保留原流程。二维工程图画布及对象列表的双击编辑不变。**Draw 3D 工具内单击实体即可选择并编辑**；Getting Started 也提供此说明。

## 编组、中心轴线对齐与紧固件插件

**编组：**在 Objects 中用 Ctrl、Shift 或 Ctrl+A 选中至少两个对象，然后点击左边栏“编组”，也可选择“编辑 > 编组”或多选右键菜单中的“编组”。对象列表出现可折叠的组标题。单击标题选中全部成员（包括隐藏成员），Ctrl/Shift 单击可切换整组选择；成员仍能单独选择，Shift 区间跟随列表显示顺序。移动、旋转、缩放等兼容工具作用于选中的成员。编组不融合几何，也不改变对象编号。左边栏“解组”、“编辑 > 取消编组”或组标题右键的“取消编组”会保留全部对象。编组关系随工程保存，支持撤销/重做。组标题还提供全部显示、全部隐藏、颜色及“删除组及对象”；最后一项会删除成员。仅支持单个对象的工具会拒绝冲突的组选择并提示原因。

**中心轴线对齐：**进入“对齐”并加入对象，勾选“中心轴线对齐”。可以拾取圆柱面、模型直边或草图直线作为目标轴，也可填写方程 `P(t) = (X,Y,Z) + t(a,b,c)`。X/Y/Z 是轴上一点，使用当前显示单位；a/b/c 是非零方向向量，不是角度。拾取圆柱时该对象保持不动。也可在选单中锁定参考对象，再点击“使用锁定对象轴线”。自动圆柱轴优先采用最长的受支持外柱面，再退到内孔；有多个不同轴的复杂零件请明确拾取。其它对象使用包围盒中心处平行于世界 X/Y/Z 的方向。应用时逐件旋转至目标轴并消除垂直偏移，保留沿轴位置和尺寸；轴线不区分正负方向，避免无意义地掉头。整批一步撤销。取消该勾选可恢复原来的最小/中心/最大对齐。

**外观与工具栏：**原来的纯文字布局改名为“简洁”。首次指引或“设置 > 外观”均可选择简洁、精密经典、石墨工作室和瓷白工坊，并记住为默认；首次指引随外观变化。打开草图菜单会收起绘制3D，反之亦然；仅收起菜单不会丢弃草稿。每个启用的插件在菜单栏下方显示简洁工具栏，点击三角/名称展开或收起完整工具，停用插件也会关闭窗口；收起时保留参数。

**螺钉生成器 / 螺帽生成器：**在“插件”中启用后，从其工具栏展开。螺钉包括六角、内六角圆柱头、沉头、手拧和螺柱；螺帽包括六角、方形、圆形和法兰。选择 M3/M4/M5/M6/M8/M10/M12 公称预设或自定义，然后修改直径、螺距、长度、头部/帽体尺寸、内六角孔、螺纹长度、旋向、径向间隙与入口倒角。标准头部/帽体尺寸仅作为参考；沉头、手拧、方形、圆形和法兰类型是自定义起始形状。未提供螺纹公差等级或强度认证。沉头长度包含头部，其它螺钉采用头下长度，螺帽长度即高度。初始轴沿 +Y，位置为底部坐标。输入显示随设置单位变化，内部仍按毫米保存。

点击“生成”后在后台计算实体螺旋网格，成功时一步提交、可撤销；须先结束当前交互工具。失败或完成前文档发生变化时不修改工程。请等待生成结束再保存。选中已生成紧固件后打开对应插件，可修改参数并“更新所选对象”，保留编号、名称和颜色；“新建副本”会创建另一个对象。参数、位姿与编组关系均随工程保存/重开。取消“实体螺纹”会生成没有螺旋切削的毛坯，螺帽毛坯仍保留小径底孔。

**打印配合：**“打印粗牙 12 × 2”提供较大直径、粗螺距的起始配对。“打印配合”设置单件径向间隙：螺钉缩小，螺帽孔扩大，不改变螺距与牙侧角。配对件须使用相同的公称直径、螺距和旋向。螺帽两端带入口倒角，螺纹切削贯通物理端面。先打印短配合试件，再制作完整零件；材料、层高、方向和打印机校准会影响所需间隙。输出为可导出 STL 的采样网格实体，不是解析制造螺纹。尺寸来源见[紧固件生成说明](FastenerGenerators.md)。

## 螺纹生成

双击圆柱外侧或圆孔内壁，选中已识别的完整柱面后，右栏才显示 **Thread generator / 螺纹生成** 入口，点击展开。也可右键选择“生成螺纹”直接展开。仅选对象、平端面或无法识别的曲面时入口隐藏；内外壁、相邻孔及端面保持独立。

孔口处仍可见的随体圆形草图与该孔端环吻合时，不会阻挡内孔壁的悬停及双击选择；无需先隐藏草图。编辑该草图时，在 Objects 列表选择它并使用 Edit Sketch。其它草图区域仍按原规则选择。

面板先显示对象名、内孔/外柱、直径、轴向长度、轴向及轴线起点，再显示 Preset。下拉菜单只列出符合当前柱面毛坯/底孔及轴向范围的公制、UNC/UNF、BSPP、BSPT 和个人预设，按几何匹配程度排序，最后为 Custom。当前预设显示名称，下方任一螺纹参数改变后自动变为 Custom。

可调整公称直径、螺距、长度、起始偏移、径向牙深、牙型角、牙底平段、左右旋、牙槽附加切深、每件径向配合余量及直径锥度。模型尺寸跟随设置中的 mm/inch，打印机喷嘴与层高始终用 mm。惠氏圆弧牙固定为 55°、牙深为 0.640327P。面板显示所需毛坯/底孔：外柱匹配大径，内孔匹配小径底孔，不能直接使用公称直径。检查后点击“生成螺纹”，只加工当前柱面，一步撤销；同一对象剩余的支持表面在保存、重开后仍可继续加工。

旧的 3D printing 预设已移除。公称直径下方的 **suggest for 3D printing** 更新打印专用螺距、齿形与配合余量；其后的 **...** 打开独立打印设置窗口。默认 **FDM、0.4 mm 喷嘴、0.2 mm 层高**，可改喷嘴和层高或切换树脂（默认 0.05 mm 层高）。设置后关闭窗口，再点 suggest 才刷新参数；只修改设置不会改动当前螺纹。FDM 建议使用宽截平牙顶/牙底、90° 牙型角和 45° 侧坡，按螺纹轴竖直打印；树脂使用 60° 截平牙。公称直径、旋向、长度和偏移保持当前值。红色 warning 说明底孔不符、尺寸或轴向范围无效、打印细节过小、层高过大或配合余量耗尽啮合深度等问题；几何无效时不能生成。

配对螺钉与螺帽应使用相同公称直径、螺距、旋向及每件径向余量 c。完整外牙向内移动 c、内牙向外移动 c，两件合计径向余量约 2c；牙槽附加切深与配合余量独立。面板显示牙顶/牙底参考直径。打印建议是试打起点，材料、方向和设备误差仍需一对短试件校准，见[打印建议说明](ThreadPrinting.md)。

最下方点击 **save as preset** 打开独立窗口，输入唯一名称并点“保存”；该窗口不再占用属性栏底部空间。完整螺纹参数、内/外牙类型及打印设置保存到用户配置目录的 `thread_presets.json`，重启后仍可调用；个人预设也遵守几何筛选。同名项不会被覆盖。

支持 STEP 中完整的圆柱面/孔壁，包括以 B 样条保存或拆为多个相连面的柱面，以及 Draw 3D 和可识别的简单圆柱特征。螺钉杆部与头部、轴肩分别选取，圆筒内外壁保持独立。导入曲面按 0.0001 mm 容差识别，并检查合并后边界确实为两端圆环；STL 网格中的完整圆柱/孔壁也可通过几何认证后整体选取：检查闭合端环及完整侧壁覆盖，网格径向拟合误差同时不超过半径的 1% 和 0.02 mm，不代表恢复原始 CAD 精度。不完整圆弧、侧壁被开口截断的柱面仍不支持。结果为**采样网格实体**，会替换该对象原有解析几何。后续需要解析曲面时，请先另存工程。这些是几何建模预设，未实现制造公差等级或量规认证。BSPT 采用 1:16 直径锥度，参数直径指起始偏移处，不是标准管螺纹的量规平面。

长度须大于螺距，且加上起始偏移后不超出可用柱面；螺距至少 0.2 mm。请求的长度/螺距最多为 125 圈，每圈采样 96 步。切削工具在请求区间的两端各延伸一圈，再裁切到起始偏移至“起始偏移 + 长度”的明确范围，内部额外采样的两圈不占用 125 圈额度。区间触及实体端面时，沟槽会贯通该端面，不留下未加工挡圈；仍可通过起始偏移和长度生成局部螺纹，不切削选定区间之外的部分。不自动添加生产退刀槽或入口倒角，当前不提供实时螺纹预览。

## Objects 列表连续选择

普通单击对象确定选择起点；Shift 单击按列表顺序选中起点到目标之间的所有可选对象（包含两端），连续 Shift 单击调整范围但不移动起点。Ctrl 单击追加/取消单个对象，Ctrl+Shift 单击追加一个区间。隐藏对象也可在对象列表中选择，作为区间起点、终点或中间项；选择不会自动显示它们，可用右键批量“可见”统一显示。草图子项在同一草图内单独连续选择，支持 Pick、Move、Rotate、Align，不跨层混选对象与图元。对象区间支持普通选择、Align、Union；不兼容的单目标工具需先结束。工作区点击手势保持不变。

选择多个对象后，对象列表右键菜单提供编组/取消编组、批量可见、颜色和删除，并显示所选数量。即使在另一行打开菜单，也作用于当前选中组；重命名只在单对象菜单显示。可见性混合时复选框显示中间态，点击统一显示，再次点击统一隐藏。颜色窗口固定使用打开时的对象组。每次批量操作只占一步撤销；删除多个对象前需先结束不兼容工具。

本指南覆盖 S33D 的主要操作。在“帮助”菜单顶部可以按工具、操作或快捷键搜索，并在紧凑的主题菜单中查看说明。


**数值工具输入：** 拉伸、挖槽、旋转体、绘制3D精确参数、变换、阵列、倒角／圆角、偏移／抽壳及平面方程工具激活时，一次性聚焦第一个可用数值框并全选原值，直接打字即可替换。工作区拖动会释放输入焦点，不会反复抢回。拉伸／挖槽拖动与深度框同步，正对法线时用上下拖动；松开固定数值，“完成”才提交。

**剖视：** 对每个实体分别判断，不相交或仅相切时，无论剖面在前后、是否 Flip，都显示完整实体；相交时正常剖切。拖动视口中的剖面箭头沿法线移动，方程以毫米实时更新；正对法线时用上下拖动。退出不修改实体和建模历史。

**剪贴板：** 编辑菜单增加复制／剪切／粘贴，快捷键 Ctrl+C／Ctrl+X／Ctrl+V。空闲时操作一个选中对象；剪切保留内部剪贴板几何，删除可一步撤销。文本框继续使用普通文字剪贴板。粘贴沿用每次 X 方向偏移 20 mm。

**3MF 几何导入：** 支持 Core 网格 build 项、嵌套组件和 Production 跨模型文件引用，保留单位、实例变换和镜像后的正确绕序；未被 build 使用的资源不生成额外对象。Z-up 转为 S33D Y-up 后，按其它网格导入方式整体居中落地，保持相对位置。不导入切片／打印机设置、贴图和颜色分配。不支持的必需扩展、加密／ZIP64、损坏包、无效索引或组件循环会明确报错，不留下部分对象。限制：包 256 MiB、单模型 XML 64 MiB、展开模型 XML 合计 128 MiB、展开后 200 万顶点／400 万三角形。一次导入可一步撤销。

**启动与外观：** 新用户或缺失外观设置时默认 Graphite Studio，已有明确选择继续保留。启动图以 3840×2160 工作区上的 768×1024 物理像素为比例基准，随分辨率缩放并居中、适配可用工作区，不改变工作区 DPI。

## 1. 界面布局

- 左侧是建模工具栏，包含草图、三维绘制、拉伸、布尔运算、镜像等命令。
- 中央是三维工作区，用于查看几何体、选择边、表面或对象，以及操作变换控件。
- 右侧包含视图、属性、新手指引和历史记录。
- “对象”浮动窗用于选择、显示、改名、改色和删除对象。
- 底部状态栏显示当前提示、单位、步长和吸附状态。

## 2. 选择对象

- 在工作区单击选择边。
- 在工作区双击选择表面。
- 选中有封闭边界的平面或草图区域后右键，可以在此表面创建草图、拉伸（E）、切除（P）、旋转或取消选择表面（Esc）。受支持的圆柱壁可从右键菜单打开螺纹生成。
- 在工作区三击选择整个对象。
- 按住 Ctrl 或 Shift 可追加或取消多选。
- Ctrl+A 选择全部可见实体；若当前工具不接受该选择，程序会清空冲突选择并说明原因。
- 在“对象”窗口中，普通单击选择一个对象，按住 Ctrl 或 Shift 单击可多选。

## 3. 视图与相机

- 按住鼠标中键拖动可环绕，按住右键拖动可平移，滚轮用于缩放。
- 等轴测、顶视、前视和右视用于切换标准视角。
- 透视和正交用于选择投影方式。
- 适合窗口会将全部可见对象纳入视野。
- 数字键 0、1、3、7 分别选择等轴测、前视、右视和顶视；数字键 5 切换投影方式。

## 4. 工程与文件

- “文件 > 新建项目”（Ctrl+N）创建空项目；“关闭项目”返回空白工作区。
- “保存项目”（Ctrl+S）将对象、几何、历史记录、撤销与重做、选择、相机、网格和吸附状态保存到 .s33d 文件，之后直接保存到当前路径。“项目另存为…”（Ctrl+Shift+S）选择新路径，并将其作为当前项目。
- “打开项目”（Ctrl+O）载入 .s33d 项目。新建、打开、关闭项目和退出程序前，若有未保存修改，会询问“保存 / 不保存 / 取消”。取消或保存失败会保留当前项目。单纯选择和相机变化不标记为模型修改；项目名旁的星号表示有未保存修改。
- 保存会完成有效的草图 / 绘制3D草稿；其它操作请先完成或取消。尚未完成的笔画或编辑不会被悄悄漏存。
- 左侧“草图”和“绘制3D”标题单击展开，再单击收起；收起保留当前草稿，展开可继续编辑。使用“退出草图 / 退出绘制3D”完成当前会话。
- 导入支持 STEP、IGES（.igs/.iges）、STL、OBJ、PLY、GLB/glTF 和 3MF（.3mf）；新导入对象自动选中。STEP/IGES 后台读取，“取消”会丢弃导入结果。
- SolidWorks：请将完整装配或零件导出为 STEP（推荐）或 IGES 后导入。S33D 保留转换后的 B-rep 几何及装配相对位置，但不恢复配合、配置、SolidWorks 特征树、原零件名称和颜色。原生 .sldprt/.sldasm/.slddrw 与 Parasolid .x_t/.x_b 需要独立转换器，当前不能直接打开。工程图不能代替对应的三维零件或装配。STL 是网格，不含原始 CAD 拓扑。
- 导出支持 GLB、OBJ、STL、PLY 和 STEP。使用 **文件 > 导出…**，在系统保存对话框选择格式：选中对象可选 STEP、STL、OBJ、PLY、GLB；已有工程图可选 SVG、DXF、PDF、EPS。打开／导入和保存／导出分别记忆读入、输出目录，重启后保留。选择一个实体并指定保存位置；后台导出显示进度及已用时间，取消或 Esc 保留原目标文件。只有完整文件写出后才显示成功。
- 网格螺纹及边缘处理结果以经过验证的平面实体导出 STEP，保留通孔和封闭空腔。微小数值接触在受限检查后清理；开口、明显自交或过大网格会报错。原有精确曲面保留 B-rep 几何。导出失败不会覆盖已有目标文件。

模型导出默认使用当前项目名及 STEP（`.step`）。可在保存对话框选择其它格式。

## 5. 对象管理

- “可见”复选框控制对象是否显示；隐藏对象不参与选择和布尔运算。
- 右键对象可改名、选择颜色、切换可见性或删除。
- 在颜色窗口中选择颜色后按“应用颜色”；“取消”放弃修改。
- 双击可编辑的草图、三维绘制对象或特征，可重新打开对应参数。

## 6. 草图

- 选择“草图”，再选择 XY、YZ、ZX、模型平面或线性方程平面。
- 直线（L）、圆弧（A）、圆（C）、矩形（R）和多边形（G）用于创建草图几何。
- 选择（V）用于选择草图图元；Ctrl 和 Shift 支持多选，右侧会显示每个所选图元的属性卡片。
- 关键点显示端点、中点和中心；磁性吸附可以使用草图及参考对象的关键点。
- “完成”结束当前绘图工具；“退出草图”保存并离开草图。
- Esc 退出草图并保留已完成的图元。绘图链还在进行时，第一次按 Esc 先结束该链。

### 修剪（Trim）

- 新建或编辑草图时选择 **修剪**。悬停以橙红色预览将删除的片段，单击剪除；工具保持激活，可连续剪除。**完成**返回选择工具，**退出草图**保存并退出。
- 以交点、直线/圆弧端点和轮廓顶点为边界，可剪掉伸出的线头或中间片段；没有分割交点的独立直线或圆会整条删除。
- 直线、圆和圆弧使用解析交点，剪开的圆保留为圆弧。矩形、多边形剪开后变为独立线段；手绘/文字轮廓按已存轮廓顶点与交点分段，不再保留原整体/文字参数编辑。其它对象不变。
- 每次单击均可用 **Ctrl+Z** 撤销、**Ctrl+R** 重做。开放轮廓需重新闭合才能拉伸；如果草图驱动已有实体，剪开时可能暂时无法重建依赖，此时保留最后有效实体，待修复轮廓后再提交。

### 手绘与文字

- **手绘**：每次按住拖动都绘制新的一笔，可以从已有笔画上起笔或穿过已有笔画。松开完成一笔，继续等待下一笔，不自动选中上一笔；每笔是一个对象和一个撤销步骤。回到起点附近会自动闭合，也可勾选“自动闭合每一笔”。开放笔画保留为线，不能直接拉伸区域。切换到 **Pick（选择）** 后可选中和拖动已有轮廓；距起点最远的红色包围角点可等比例缩放。
- **文字**：单击工作区放置透明的虚线文字方框及基线起点，可在方框或右边栏输入最多 64 个字符，两处实时同步。所有属性和操作按钮均位于右边栏。选择 Noto Sans SC（支持中文）、Ubuntu Light 或 Hack，并设置“字号”。字号是当前长度单位下的字体 em 高度，不等于实际可见字高。右边栏“完成”关闭方框并保留文字对象。
- 选中文字对象可以修改位置、字号和顺时针角度；改变内容或字体会实时原位更新同一对象。项目保存字形轮廓，包括 O/B/8 的孔洞和汉字笔画，换电脑打开不需要安装字体。内置字体保留各自的分发许可证，见 `THIRD_PARTY_LICENSES.md`。
- 虚线方框内直接显示最终建模的真实字形、位置、字号和旋转角度，不另画一份界面字体预览。在框内按 **Enter** 完成，**Shift+Enter** 换行；中文输入法确认候选字时不会提前完成文字对象。
- 退出草图，单击任一实心笔画即可选中该文字对象的全部实心区域，再一次拉伸全部文字，字内留白仍保持孔洞。Ctrl/Shift 可追加或取消同一草图中的整组文字。在草图中选中文字对象也可以直接拉伸。归组不会连接字间空隙。过于复杂的文字请拆成较短对象。目前是简单轮廓文字，不是富文本排版器。

## 7. 草图移动、旋转与对齐

- 草图移动支持多选、数值偏移、当前步长和四个即时方向按钮。
- 草图旋转的正角度为顺时针；顺时针和逆时针 90 度按钮会立即生效。
- 自定义枢轴使用草图平面上的点指定旋转中心。
- 可在属性中为直线、圆弧、矩形和多边形选择锁定点。默认锁定最先放置的点，多边形默认锁中心，也可改锁任一顶点。移动时锁定点随图元移动，修改尺寸、角度或旋转时保持该点的位置。选“不锁定”可改用共同或自定义旋转中心。
- 草图对齐需要至少两个图元；锁定参考图元，选择世界坐标轴及最小、中心或最大方式，然后按“应用”。
- 移动和旋转的虚线几何是待提交预览；“应用”提交，“重置”恢复预览值。

## 8. 三维绘制

- 在草图或三维绘制创建过程中，可直接点选其它顶层工具：有效改动会先应用、完成并退出；空草图、选平面阶段和尚未放置的基本体不会产生多余对象。切换三维基本体类型也会先提交已放置的预览。应用失败时保留当前现场供修正。草图移动/旋转的数值预览会在切换工具时应用。目标工具仍要求其正常所需的对象或封闭区域，不会自动猜测选区。

- 三维绘制可创建长方体、圆柱体、球体、圆锥体和圆环体。
- 第一次单击放置基础点，移动指针改变大小，再次单击确认初始尺寸。
- 右侧可精确设置基础位置、宽度、深度、高度、半径等参数。
- 球体的首次单击及“球心位置”设定的是中心，而非底部；改变半径时球心保持不变。输入数字和拖动期间使用轻量显示预览，点击“应用”才生成并验证精确球体，再点“完成”提交。旧工程不会移动。Agent `primitive.create` 的 position 为兼容旧脚本仍指基点：默认世界朝向下，球心 C 对应 position = C − (0, 半径, 0)。
- 第二次单击后，拖动预览体或蓝色基点可在自身底面内移动；拖动红色关键点可调整宽、深、高、半径等尺寸。随动读数和右侧属性同步更新，提交前可以反复拖动。
- 修改只影响预览，依次按“应用”“完成”才提交；应用后再次改动需重新应用。编辑已有基础体会保留其对象 ID。
- “应用”更新当前对象，“完成”创建对象；三维绘制仍激活时，可重新选择已创建的基础体继续编辑。
- 点击“应用”后，按 Esc 提交当前基础体并退出三维绘制。“退出三维绘制”也可提交有效的已放置预览。

## 9. 拉伸、切除与旋转体

- 开始拉伸、切除或旋转体之前，需要选择闭合草图区域或具有固定边界的平面表面。
- 拉伸使用深度参数，也可启用对称方式。
- 选好封闭区域后按 P 切除。切除会采用已选实体、唯一关联的可见实体，或根据轮廓位置推断唯一目标。若有多个候选，在工作区单击目标。
- 切除使用深度，或启用贯穿以完全切穿目标实体。深度预览从草图平面向内显示所填深度；贯穿预览覆盖目标沿切除方向的范围。
- 盲孔切除完成后，已用于该切除的草图不会挡住对应平面坑底的悬停或双击选择，前提是实际孔口与坑底轮廓仍吻合。编辑草图时在 Objects 中选中它；移动过、改过轮廓、无关或共面的草图区域仍按原规则选择。
- 旋转体需要选择旋转轴，角度以顺时针为正。
- “应用”或“完成”提交操作；Esc 取消操作。

## 10. 移动、旋转与缩放

- 移动支持一个或多个对象；可拖动变换控件，也可输入世界 X、Y、Z 偏移。
- 六个方向按钮按当前步长立即移动。
- “移动到”会把所选对象组的共同中心放到精确坐标。
- 旋转支持世界轴、模型直边和草图直线；正负 90 度按钮会立即旋转。
- “按百分比缩放”使用百分比；“缩放到尺寸”使用精确包围盒尺寸。
- “等比例缩放”保持比例；关闭后可分别缩放各轴。

## 11. 对齐

- 对齐可以在没有选择或只选择一个对象时启动，再从“对象”窗口或工作区加入更多对象。
- 第一个有效对象默认成为锁定参考；需要时可在对象列表中改选锁定项。
- 选择坐标轴以及最小、中心或最大方式，检查预览后按“应用”。
- 对象列表过长时可以滚动，坐标轴、方式和“应用”仍优先显示。

## 12. 布尔运算

- 并集支持多个对象；所选操作数使用统一预览色，按“应用”后合并。
- 差集计算“原对象（A）”减去“减去对象（B）”。“交换对象”一键交换两栏，不会立即执行运算。
- 交集使用相同的两个输入槽，并保留共同体积。
- 单击任一对象输入框可展开可滚动的可见实体菜单，显示名称和编号；也可在工作区或对象列表点选。若选到另一栏已有的对象，会将它移至当前栏，清空另一栏并等待重选；两栏齐备后才能应用。“保留原对象”决定是否保留来源对象。
- 布尔预览不会修改工程，必须按“应用”才正式生效。

## 13. 镜像、分割与剖面视图

- 镜像：选择一个或多个对象，选择镜像平面，再按“应用”。
- 分割：选择对象和切割平面，再按“应用”生成独立实体。
- 剖面视图只改变观察方式，不修改几何；按 Esc 退出。
- 平面可使用 XY、YZ、ZX、模型平面或 ax+by+cz=d 线性方程。
- “翻转侧面”显示另一半；“保留原对象”决定是否保留来源对象。

## 14. 倒角与圆角

- 启动倒角或圆角后，选择一条边或连续边链。
- 倒角使用距离，圆角使用半径。
- 凸斜边的半径指与两侧相切的圆半径，不是沿面的退让距离；实体内角越尖，需要的退让空间越大，邻近几何空间不足时应减小半径。软件更新不会自动修改已保存的网格结果：重新编辑该特征并应用，才能按新算法重建。
- “应用”立即修改实体；同一条边修改参数后再次应用会更新当前特征。在另一条边应用会自动保留前一次修改，并以已有结果为基础创建下一处特征，无需先点“完成”。
- “完成”可手动结束当前边并继续选边；“退出倒角/圆角”会先应用最新参数并完成当前边，再结束工具、收起菜单。双击选面或三击选对象也会退出工具，并执行对应选择。
- 可在“对象”窗口重新选择特征并修改参数；删除中间特征会重建后续依赖。

## 15. 阵列、复制、粘贴与删除

- 阵列可同时启用 X、Y、Z 轴，并分别设置方向、间距和副本数。
- 副本数包含原对象。
- 复制保存所选对象，粘贴按递增偏移生成副本。
- “删除”或 Del 键会移除当前所选对象。

## 16. 单位、步长与吸附

- “设置 > 单位”可选择毫米、厘米、米、英寸和英尺。
- 模型和工程文件内部始终使用毫米；更改显示单位不会改变真实尺寸。
- 状态栏显示当前单位；步长会换算为该单位下的等效值。
- 开启吸附后，草图和移动会对齐步长网格；关闭后可使用连续坐标。

## 17. 撤销、重做与历史记录

- Ctrl+Z 或“编辑 > 撤销”用于撤销上一次文档修改。
- Ctrl+R、Ctrl+Shift+Z 或“编辑 > 重做”用于恢复修改。
- 撤销与重做会恢复文档几何和对象选择；活动草图使用独立的会话时间线。
- 历史记录显示近期操作，但选择消息不一定代表可撤销的几何事务。

## 18. 科学计算器

- 启动时扫描可执行文件旁的 `Plug-ins/*/plugin.json`（Cargo debug/release 开发构建使用项目根目录的 `Plug-ins`）。只有受支持且有效的 `builtin:<id>` 清单才列为已安装；删除清单后重启，对应菜单项消失。目前不加载任意 DLL 或脚本。未知、无效、重复清单会在插件菜单中提示。发布时需将 Plug-ins 文件夹与程序一同分发，扫描不依赖当前工作目录。
- 插件菜单按名称、启用开关、打开操作左对齐。开关拨到右侧启用、左侧停用，状态会保存；“打开”也会启用对应插件。启用后从菜单栏下方紧凑工具栏展开/收起，收起保留参数。安装或移除清单后请重启。

- 可从“插件”菜单启用或打开计算器。
- 支持四则运算、幂、括号、上次答案、圆周率、自然常数、平方根、三角函数、反三角函数、对数、绝对值和指数函数。
- 角度制和弧度制用于选择三角函数的输入方式。
- Enter 或等号执行计算；C 清空；退格按钮删除最后一个字符。

### 生成器与表面插件

- “齿轮生成器”“轮胎生成器”“轮毂生成器”和“表面纹理”都是可从“插件”菜单启用的内置可选工具。
- “轮胎生成器”按外径、轮辋直径、断面宽、胎纹深度和重复数生成公路纵纹、块状、人字或全地形轮胎。
- “轮毂生成器”生成五辐、六辐、双五辐或多辐轮毂，并可精确设置轮心、中心孔及螺栓孔尺寸。
- “表面纹理”需要先选择一个平面或参数化圆柱侧面，可生成直纹、左右斜纹或菱形滚花，并可编辑节距、槽宽、深度、角度和留白。
- 生成对象会保留参数。选中对象并重新打开对应插件，即可在保持 Object ID 不变的情况下更新；表面纹理会把源对象作为隐藏的非破坏依赖保留。

## 19. 设置与新手模式

- 设置可控制语言、字体、字号、外观、强调色、单位、首次使用提示、新手模式、Agent 控制和调试日志。Agent 控制的启用开关、端口、连接测试、注册与取消注册集中在同一个子菜单中。
- 首次使用提示可以切换外观、语言和默认单位，也可以启用分步指引。
- 关闭新手指引会停用该指引并保存选择。

## 19.1. 外观与工具图标

在**设置 > 外观**中选择四种样式：

- **简洁**（默认）：保留原有紧凑的纯文字工具栏，仍可通过“强调色”选择蓝色、青色或橙色。
- **精密经典**：暖白面板、深灰工作区和青色控件。
- **石墨工作室**：深色面板与工作区，搭配暖橙色控件。
- **瓷白工坊**：浅色面板与工作区，搭配靛蓝色控件。

三种新样式使用同一套原创 CAD 矢量图标，并保留文字标签和原有工具顺序。工具栏略宽，空间不足时可滚动；草图与绘制三维工具组可以折叠。各预设使用自己的强调色，独立的“强调色”设置作用于简洁外观。

切换后立即生效并保存，重启后仍保留。外观仅调整界面与工作区配色，不修改模型几何、对象颜色、选择状态或相机视角。

## 20. Agent 控制（Codex 与 Claude Code）

Agent 控制允许本机 AI 编程 Agent 或脚本读取并修改 S33D 当前打开的文档。桌面程序仍是文档、几何内核、选择状态、视图、历史记录及撤销与重做状态的唯一所有者；桥接程序不会维护另一份模型。

- 数据流：Codex 或 Claude Code 通过标准输入输出上的 MCP 启动 `s33d-agent.exe`；桥接程序默认通过 `127.0.0.1:53433` 向 S33D 桌面程序发送逐行 JSON；S33D 在界面线程中使用现有 Document 和 TruckKernel 执行通过验证的命令。
- 本机脚本可直接使用桥接程序的命令行模式，不必使用 MCP。默认回环地址只能由同一台电脑访问。
- 协议 v2 在读取过程中限制每帧 1 MiB，最多 8 个连接、16 个排队请求。排队命令 30 秒过期后不会延后执行；已开始的运算返回 `in_progress`，此处不能强制中断。交互式工具尚未结束时，修改模型的命令返回 `busy`。
- MCP 写命令必须预先填写 `idempotency_key`；命令行支持 `--request-key`。超时重试保持方法、参数、键完全一致，不能因结果不明就换键。`request.cancel` 的参数 `{"idempotency_key":"原请求键"}` 可取消尚未开始的命令。去重记录仅在同一监听器持续运行且完成后 10 分钟内保留，重启/改端口会重置；最多 256 条、输入总计 8 MiB，满时返回 `server_busy`。响应缓存限制和恢复办法见 AgentControl.md。

运行所需文件与进程：

- `s33d-app.exe` 是桌面宿主，必须保持运行，并打开需要编辑的工程。
- `s33d-agent.exe` 是配套的 MCP 与命令行桥接程序；两个可执行文件应来自同一次编译。
- 关闭 S33D 会同时结束已连接的 MCP 桥接进程。重新打开 S33D 后，如果 Agent 未自动重连，请重启 Agent。
- Codex 需要在 `config.toml` 中加入一个 `mcp_servers.s33d` 条目；Claude Code 需要在工作工程的 `.mcp.json` 中加入一个 `s33d` 条目。
- 配置示例位于 `agent-config/codex.toml.example` 和 `agent-config/claude-code.mcp.json.example`；它们只是配置模板，不是额外的运行程序。
- S33D Agent 控制本身不需要云服务账户、API Key 或在线几何服务；所使用的 Agent 软件可能有自己的账户要求。
- Agent 控制默认开启。“设置 > Agent 连接”中的“启用本机控制”可立即启动或停止本机监听并保存选择；关闭监听不会修改模型或历史记录。
- 端口输入范围为 1 到 65535，默认为 53433。输入数值后按“应用端口”；若端口已被占用，S33D 会保留原监听，并提示更换端口后重试。
- “测试连接”会在必要时先应用刚输入的新端口，再确认 S33D 的本机回环监听能够接受连接。
- Codex 和 Claude Code 各自提供“注册 / 更新”和“取消注册”。注册前会先测试当前端口，然后只修改该 Agent 用户配置中的 `s33d` MCP 条目；取消注册也只移除这一条，不会删除 S33D 或任何工程。
- 若缺少 Agent 命令行工具，请先安装或打开相应 Agent 后重试；若配置受保护，请授予 S33D 修改该 Agent 配置的权限后重试。

在仓库根目录编译并启动两个程序：

```powershell
cargo build --release -p s33d-app --bin s33d-app --bin s33d-agent
target\release\s33d-app.exe
target\release\s33d-agent.exe status
```

最简单的 Codex 配置方法是“设置 > Agent 连接 > Codex > 注册 / 更新”。S33D 会在当前运行程序旁自动找到桥接程序，因此每台电脑都会写入各自正确的绝对安装路径。手动配置时，请把 `<S33D_INSTALL_DIR>` 换成该电脑上的安装目录：

```powershell
codex mcp add s33d -- "<S33D_INSTALL_DIR>\s33d-agent.exe" mcp
```

macOS 或 Linux 使用 `codex mcp add s33d -- "<S33D_INSTALL_DIR>/s33d-agent" mcp`。

也可以把以下条目合并到 Codex 的 `config.toml`：

```toml
[mcp_servers.s33d]
command = '<ABSOLUTE_PATH_TO_S33D_AGENT>'
args = ["mcp"]
```

这里使用 TOML 单引号，因此 Windows 反斜杠可直接填写。若手动编辑 JSON 配置，请把每个 Windows 反斜杠写成 `\\`，或者改用正斜杠。

最简单的 Claude Code 配置方法是“设置 > Agent 连接 > Claude Code > 注册 / 更新”。其等效的用户级命令如下：

```powershell
claude mcp add --transport stdio s33d --scope user -- "<S33D_INSTALL_DIR>\s33d-agent.exe" mcp
```

macOS 或 Linux 使用 `claude mcp add --transport stdio s33d --scope user -- "<S33D_INSTALL_DIR>/s33d-agent" mcp`。

如需工程级 Claude Code 配置，可将 `agent-config/claude-code.mcp.json.example` 复制为工作工程中的 `.mcp.json`，也可以把其中的 `s33d` 服务条目合并进已有文件。修改 MCP 配置后应重启 Agent 软件。

对于其他支持 MCP 的 Agent，点击“其他 Agent 手册...”会在独立窗口打开本章节。把标准输入输出 MCP 服务的命令设为 S33D 同目录下 `s33d-agent.exe` 的绝对路径，唯一参数设为 `mcp`；桥接程序会自动跟随 S33D 保存的端口。macOS 或 Linux 使用 `<S33D_INSTALL_DIR>/s33d-agent`。

MCP 桥接程序提供六个工具：

- `s33d_describe` 返回实时协议版本、全部方法、参数格式、单位和示例。每次开始工作时先调用它，不要猜测参数。
- `s33d_state` 返回当前文档、选择状态、稳定的实体 ID、特征、草图图元与封闭区域、三角面数量、可见性和世界坐标包围盒。
- `s33d_execute` 使用参数对象执行一个目录中的方法。常用方法包括 `primitive.create`、`sketch.create`、`feature.extrude`、`feature.revolve`、`body.transform`、`boolean.apply`、文件与工程命令以及历史命令。

- `s33d_workflow` 返回所选工作流程的内置建模指南。
- `s33d_reference` 列出工程中的可选参考照片，也可以通过资产 ID 读取单张已导入的照片。
- `s33d_render` 返回 S33D 原生模型图，供检查和对照。

新增命令：`sketch.trim.preview` 接收 `sketch_id`、草图平面内 UV 坐标 `point:[u,v]` 和以毫米为单位的正数 `tolerance`，只返回待删片段、剩余片段、新区域及 `preview_token`，不修改文档。提交时用相同参数与该令牌调用 `sketch.trim.apply`，保留草图实体 ID、重建受支持的后续特征，并支持撤销/重做。草图或参数变化后须重新预览；依赖重建失败不会修改文档。预览本身不验证后续特征。仅支持空闲状态下已提交的 Sketch，不支持实体或方程曲线；整体轮廓修剪后变成片段，操作后要重新查询区域编号。`view.recenter` 使用空参数 `{}`，将可见模型重新居中并恢复透视视图，不修改几何（仅限空闲状态）。

建议 Agent 按以下顺序工作：

- 启动 S33D，并完成或取消桌面程序中尚未结束的交互工具。
- 先取得 `s33d_workflow` 与 `s33d_describe`，修改模型前通过 `s33d_execute` 读取 `document.summary`；需要完整几何细节时再用 `s33d_state`。
- 通过 `s33d_execute` 一次执行一个操作，使用 S33D 返回的实体 ID 或草图区域编号。
- 操作后重新查询文档摘要，检查特征类型及包围盒，并用 `s33d_render` 查看原生模型图；`s33d_reference` 用于可选的工程内照片。结果不正确时调用 `history.undo`。
- Agent 控制中的长度和坐标始终使用毫米，即使界面当前显示其他单位；角度使用度。

下面的直接命令行示例会创建一个 40 × 20 × 8 mm 的长方体：

```powershell
target\release\s33d-agent.exe call primitive.create '{"kind":"box","name":"Base","position":[0,0,0],"width":40,"depth":20,"height":8}'
```

使用 `target\release\s33d-agent.exe describe` 查看当前程序实际支持的完整命令，使用 `target\release\s33d-agent.exe call document.get` 在没有 MCP 客户端时读取模型。如果 `status` 无法连接，请在“设置 > Agent 连接”中勾选“启用本机控制”。开关下方会显示当前监听地址。若未通过 `--address` 或 `S33D_AGENT_ADDRESS` 明确覆盖，桥接程序会从各系统的 S33D 用户配置目录读取端口：Windows 为 `%LOCALAPPDATA%\S33D`，macOS 为 `~/Library/Application Support/S33D`，Linux 为 `$XDG_CONFIG_HOME/s33d`。旧版工作目录设置会自动迁移。启动 S33D 前设置 `S33D_AGENT_DISABLE=1` 可在环境层强制关闭监听。

协议提供确定性的、基于编号的创建与编辑。精确偏移提供当前源对象的拓扑面索引，但不代表所有操作已有通用稳定边编号；圆角边的目视选择仍使用桌面操作，除非实时接口目录明确支持。

## 22. 空间曲线与精确几何

### 三维方程曲线

选择与“草图”“绘制3D”并列的“方程绘图 / Draw Equation”，不需要选择草图平面。填写 x(t)、y(t)、z(t)，或切换为 R(t)、theta(t)、phi(t)。设置有限且递增的 t 定义域以及表达式长度单位（毫米 / 英寸）。角度默认弧度，勾选后使用度。球坐标中 theta 是 XY 内从 +X 朝 +Y 的方位角，phi 是从 +Z 量起的极角；均采用世界坐标，不随视图改变。

螺旋线示例：`20*cos(t)`、`20*sin(t)`、`2*t`，定义域 0 至 12.5663706144，弧度、毫米。支持 sin、cos、tan、asin、acos、atan、sqrt、exp、ln、log（以 10 为底）、abs、pi、e、括号及 + - * / ^，乘法须显式输入。每式最多 256 字节；显示采用有上限的近似采样。无效坐标、负半径、无法解析的断点会使预览失败，请缩小定义域或简化方程。

输入会实时刷新预览。“应用预览”重新计算，“完成”或“退出方程绘图”提交并退出。中途转选工具也会先提交有效内容；无效输入或依赖重建失败会保留编辑现场。取消丢弃草稿。可在对象列表或工作区曲线上点选；双击对象行或点击“编辑方程”重新编辑，保持对象编号。方程、单位、变换支持保存重开和撤销重做。

位于同一平面的方程线可像草图一样双击闭合区、高亮，再进行拉伸或切除。只有一个闭合区时，也可从 Objects 选中曲线后直接拉伸。例如 `20*cos(t)`、`20*sin(t)`、`5`，定义域 0 至 6.28318530718。普通平面拉伸仍默认不对称；改方程会重建关联的拉伸/旋转体，失败保留原文档。非平面曲线不会强行压平，开放端点不会强行封口。曲线本身不是实体，不能直接作为网格/STEP 导出；保存工程保留定义。

### 联合平面选区与精确面拉伸

同一平面上的可见方程曲线现在共同划分封闭区：两个同心闭合圈可选圆环或内圆，两条开放曲线也可由实际相接的线段共同围成面域。先双击所需区域，再拉伸/切除/旋转；隐藏曲线可将其排除。不同平面的曲线不会被投影加入。多个曲线共同生成的拉伸/旋转体保存完整轮廓快照，不会只关联其中一条；后续改曲线不会自动重建该结果。单曲线关联特征仍保留原有自动重建行为。Agent 改曲线或显隐后应重新查询区域，用 `feature.extrude` 的 `region_indices` 明确选择。

精确 B-Rep 对象的完整平面面域直接拉伸时，使用原始边界（包含曲边和内孔），再与原对象合并；包括球壳切分后的平面口沿。不会以显示三角网格的折线替代真实边界。对称平面拉伸输入的是总深度，两侧各一半；它与弯曲方程曲面的局部法线加厚不同。非法或自相交结果仍拒绝提交，原对象保持不变。

### 方程曲面与填充

在“方程绘图”选择“曲面”，填写 x(u,v)、y(u,v)、z(u,v)，或 R/theta/phi，以及两组有限且递增的定义域。坐标、角度和长度约定与画线一致。各参数细分数为 4–64，采样后生成光滑 B 样条边界表示；这是插值近似，不是符号精确解，也不保证采样间误差。请避免断点、自交和过低采样；提高细分数会改变插值并增加计算量。

马鞍面示例：`u`、`v`、`0.02*(u^2-v^2)`，两组定义域均为 -10 至 10。闭合球面示例：球坐标 R=`10`、theta=`u`、phi=`v`，u 为 0 至 6.28318530718，v 为 0 至 3.14159265359，使用弧度。“填充闭合曲面为实体”只接受自身闭合、拓扑有效且体积为正的曲面，不给开放曲面自动封口。不勾选则生成曲面对象。

输入变化会请求后台预览。“应用预览”重新计算；预览成功后“完成”或“退出”提交。转选工具会提交已就绪的有效草稿；仍在计算或存在错误时停留编辑器，待预览成功后重试。取消丢弃草稿和迟到结果。切换线/曲面会替换未提交草稿。选中结果后“编辑方程”或双击对象行可保持编号改参；保存重开及撤销重做保留方程与几何，曲面支持 STEP 导出。

选择未填充的方程曲面，点击“拉伸”：沿曲面各处法线加厚，不沿固定世界方向。仅此入口默认勾选“对称”，总厚度 2 毫米表示两侧各 1 毫米；取消勾选则单侧加厚。应用预览、检查后完成；可保留原物体。不可行厚度或自交会报错且不提交。结果保存冻结源快照，之后修改方程不会重建已有加厚结果。

Agent 使用实时目录里的 `surface.equation.preview/apply`；曲面拉伸通过 `feature.offset.start`，模式为 `SymmetricThickenSurface`、distance 为正的总厚度、faces 为 []，随后 status/commit/cancel。原生计算可能耗时，取消丢弃结果但不强制终止计算。

### 精确偏移与抽壳

重新导入原始 STEP，保留真实解析 / 样条曲面及拓扑。选一个对象后进入“精确偏移 / 抽壳”，选择曲面偏移、实体抽壳或开放曲面加厚。实体抽壳需要在工作区或可滚动的面列表中选择移除面。设置厚度与容差，应用预览、检查后完成。对于朝外定向的实体，负厚度向内。“保留原物体”不勾选时隐藏源对象，并不删除。取消会丢弃预览，包括稍后返回的后台计算结果。

开放曲面标记为曲面对象。抽壳 / 加厚成功结果须为有效封闭实体；不可能的厚度、自交或无效输入会报错并保留原对象。不限制输入为规则体，但不保证任意模型及任意厚度都成功。STL / OBJ 和旧网格工程无法恢复原始光滑曲面，有原始 STEP 时请重新导入。结果保存冻结的输入快照，不自动跟随上游编辑重建。工程版本 2 在保存重开、撤销重做中保留精确几何；旧程序无法读取版本 2。

Agent 新增 curve.equation.preview/apply 和 feature.offset.start/status/commit/cancel，具体参数以实时目录为准。抽壳开始后使用返回的 job_id 查询状态；ready 只代表预览就绪，须 commit 才写入文档。面的编号是当前对象从零开始的拓扑索引。取消只丢弃结果，不强制中断本地几何计算。

## 23. 常见问题

- 看不到对象：检查“对象”窗口中的可见性，使用“适合窗口”，并确认剖面视图没有隐藏对象。
- 无法选择：确认对象可见，并确认当前工具接受该对象类型。
- 字符显示为方框：确认 Windows 已安装合适字体，然后重启 S33D 以重新加载字体回退。
- 操作不可用：按提示选择区域、表面、边或对象；若其他工具仍激活，可按 Esc 退出。
- 布尔运算或倒角失败：检查对象是否相交、参数是否适合局部几何，并尝试更小的数值。
- Agent 无法连接：保持 S33D 运行，确认 `s33d-agent.exe status` 成功，检查桥接程序和桌面程序使用相同回环地址，并确认没有另一个 S33D 实例占用端口；若端口被占用，请在设置中更换端口并再次按“应用端口”。
- Agent 返回 busy：完成或取消当前草图、三维绘制、布尔、镜像、分割、剖面视图、拉伸、切除或旋转体操作，然后重试命令。

## 24. 二维工程图

点击左栏 **三视图工程图**。菜单可展开、收起，并与草图、绘制3D互斥；收起后再次展开会保留当前图纸，切换到建模工具则回到三维工作区。

1. 三视图直接继承对象列表的选择（包含明确选中的隐藏对象）。在对象列表选择一个或多个三维对象，点击 **生成 / 刷新**。未选择对象时使用全部可见几何。生成成功前保留原三维工作区及相机视角，不切换为空白图纸。后台生成前视、俯视、右视三个视图，放在 A4 横向图纸上并使用统一适配比例。采用第三角投影，固定世界方向为：前视 X/Y（从 +Z 观察），俯视 X/-Z（从 +Y 观察），右视 -Z/Y（从 +X 观察）；转动相机不改变出图方向。
2. **自动标注** 包含整体尺寸、已确认的圆柱/孔径、中心间距尺寸链，以及不同的直线轮廓长度和台阶尺寸；圆形特征增加中心标记。附加的 **关键尺寸明细** 页列出每个源对象的 X/Y/Z 包围盒尺寸、世界位置、已确认的圆柱/孔径、轴向长度、轴起点/方向、已知倒角/圆角/偏移/螺纹参数及水平/垂直轮廓关键坐标。通过属性栏的图纸翻页按钮查看。这些是几何测量值，不推断设计公差和制造要求；任意网格不会自动被当成精确圆孔。
3. **手动标注** 可选择智能尺寸、宽度 / 水平、高度 / 垂直、长度 / 对齐、直径 Ø、半径 R。单击高亮边、圆或圆弧，再单击放置尺寸；线性工具也支持依次选取两个真实端点或圆心，再放置；放置前会随鼠标预览尺寸。对齐长度测量当前投影中的距离，不是斜向三维边的空间长度。Esc 取消未完成的选点；无待选点时再按 Esc 退出工程图。
4. 图纸激活时，撤销标注、Ctrl+Z 和编辑 > 撤销操作图纸标注；Ctrl+R、Ctrl+Shift+Z 和编辑 > 重做可以恢复。清除标注和自动标注各作为一步撤销，标注历史最多 200 步；不修改原模型。
5. 可修改图纸标题，在左栏展开菜单或右栏点击 **导出**，也可选择 **文件 > 导出…**，在系统保存对话框选择 SVG、DXF、EPS 或 PDF；工程图面板仍保留格式子菜单。SVG/DXF/EPS 输出主图和同目录的全部 `-dimensions-N` 尺寸明细页，请一起保存；PDF 将所有图纸合为一份多页文档并嵌入中文字库。所有格式保留矢量线条、A4 图幅以及当前设置单位下的尺寸文字。打印时选择 100% 才能保留图中所示比例。
6. 右侧属性栏的 **当前选择 · 三维预览** 保留源对象颜色，随对象列表选择即时更新。它是界面核对用的参考图，不打印到导出图纸；图纸仍是独立快照，改变选择后需要点击生成 / 刷新。预览完整绘制所选网格并按深度消隐、适配尺寸，不改变模型和投影轮廓。

轮廓来自网格特征边、轮廓边，并在线上实际采样位置进行三角面深度测试，并非原生精确消隐（HLR）；曲线为折线近似，极小或几乎重合的细节可能遗漏。单张图限制输入 200,000 个三角面，大装配请减少选中对象。密集尺寸延续到附加明细页，不直接丢弃；用于生产前仍需审核并按需补充手动标注。

工程图快照、尺寸与位置、文字替换、标题栏及零件说明随 .s33d 保存，重开时恢复；仅修改工程图也会触发未保存提示。投影生成期间需等待完成再保存。旧工程缺少图纸字段时加载为空图纸；标注撤销/重做历史、未完成选点、编辑器及后台任务不保存。模型修改后仍需手动刷新，图纸不与几何自动关联。 刷新会替换标注并清空标注历史；新建工程清空图纸，打开工程恢复其保存快照。本版尚未提供精确 HLR 和形位公差等高级标注。

### 特征标注与图纸格式

三视图工程图的三维预览会完整适配所选模型，并使用深度测试绘制全部三角面。点击生成 / 刷新获取工程图快照；“隐藏边虚线”可显示封闭内部轮廓。投影仍基于离散网格，并非精确剖视图。

勾选手动标注或直接选择尺寸工具。智能尺寸识别整条直边、圆和圆弧，先高亮，再单击选取，第二次单击放置尺寸。宽度 / 水平、高度 / 垂直、长度 / 对齐也可依次选取两个端点或圆心。直径 Ø 与半径 R 必须选中识别出的圆形特征，不把任意两点间距冒充直径。Esc 取消待放置标注；标注撤销 / 重做与模型历史独立。

自动标注在视图中显示孔 / 柱面的对象及特征编号，右上特征表列出直径、深度 / 轴向长度和圆心位置；超出容量的内容延续到附加尺寸页。位置基准为当前视图包围框的左下角，坐标轴按视图标明。斜向圆孔和圆柱的端口按椭圆投影识别，可用智能、直径或半径工具拾取；直径取真实长轴尺寸，不把短轴缩短量当作孔径，自动标注和特征引线也覆盖这些斜向特征。圆弧可标注半径。隐藏轮廓的关键坐标及长度列在尺寸明细中。网格拟合的圆与圆弧属于离散几何测量，不推断设计公差。

新生成的螺纹会保存所作用表面的轴起点、轴方向及参数，用于标注位置、直径、螺距、长度和起点偏移。旧记录没有保存螺纹表面位置，只保留参数明细；需要重新生成螺纹才能提供可靠位置引线。几何被后续修改而不再匹配时，不使用失效位置。

展开“标题栏”可填写图号、版本、材料、制图人、审核人和日期。右下标题栏同时显示名称、A4 图幅、比例、单位及页码；主图和附加尺寸页导出时共用相同格式，隐藏边保留虚线。标注与图纸设置随 .s33d 保存；SVG/DXF/EPS/PDF 用于交换与打印。

### 编辑已生成的图纸

尺寸工具激活时，先选择 **编辑图中文字 / 尺寸**。单击图中文字或标题栏空白单元格，在右栏 **所选文字** 中填写，点击 **应用文字** 或按 Enter。编辑区会自动滚动到可见位置。名称、图号、版本、材料、制图、审核和日期会同步到全部图纸的标题栏；特征表及尺寸明细等其它文字可以逐页替换，点击 **还原文字** 恢复自动生成的内容。替换只改变标注文字，不改变源模型及几何测量值；替换记录对应当前生成的文字和页码，切换单位/语言不会把旧数值冒用为新单位。

在编辑状态可拖动普通文字、特征编号及标题栏文字，特征引线保持原锚点；拖动尺寸数字可调整对应尺寸线的位置。模型生成的投影线保持锁定。选中尺寸文字后点击 **删除此尺寸** 可删除该项标注。文字、标题栏字段、尺寸位置及删除均支持工程图撤销/重做；所有格式导出的全部页使用修改后的内容。刷新会生成新快照，并清除尺寸、文字位移和自动文字替换，标题栏字段保留。编辑内容随 .s33d 保存，重开后可继续编辑；标注撤销历史不保存。


### 24.4 导出格式

左侧工程图展开菜单与右侧属性栏均提供 **导出**，**文件 > 导出…** 在系统保存对话框提供工程图格式；面板保留格式子菜单。文件扩展名必须与格式一致，错误扩展名会被拒绝。

- **SVG：** 每张图纸输出一个可编辑矢量文件，修改过的文字保留并进行 XML 转义。
- **EPS：** 每张图纸一个 EPSF-3.0 矢量文件，包含当前标注文字、位置、旋转和隐藏线虚线，随附全部尺寸明细页。内嵌当前页所需的 TrueType 字形，数字使用文本指令，中文保留 Unicode 字形名称。S33D 中模型投影线锁定；外部编辑器导入后能否保持文字及锁定状态取决于其 EPS 导入器，EPS 本身不提供不可编辑的权限锁。
- **DXF：** ASCII R2000 交换图，包含可编辑的 LINE/TEXT 实体，轮廓 OUTLINE、标注 ANNOTATION 和隐藏线 HIDDEN 分层，保留隐藏线虚线。坐标使用 **按图中比例缩放的纸面毫米**，即使尺寸文字使用英寸也不改变纸面坐标；这不是 1:1 模型空间输出。尺寸为线条和文字，不是关联 DIMENSION 约束。文字采用 Unicode 转义和 Noto Sans SC 字体样式，接收 CAD 需有合适的中文字体才能显示中文标注。
- **PDF：** 一份 A4 横向多页文档，包含主图及全部尺寸明细。线条为矢量路径，内嵌现有 OFL 许可的 Noto Sans SC 字库，中文可跨机器显示、搜索和选择。打印应选 100% 并关闭适应纸张，才能保持图中比例。

**暂未内置 DWG。** 菜单会说明需要另行许可的写入器；可先导出 DXF，再由用户持有许可的 CAD 软件另存 DWG。S33D 不捆绑 ODA SDK/转换器，也不链接 LibreDWG。LibreDWG 采用 GPL-3.0-or-later，ODA SDK 的发行有订阅和许可要求。这是当前发行方案的选择，不代表 DWG 格式本身违法。参考 [LibreDWG](https://github.com/LibreDWG/libredwg) 和 [ODA 许可](https://www.opendesign.com/pricing)。

所有格式使用当前标题栏字段和文字替换，不修改模型，不提供精确 HLR、不推断设计公差，也不打印界面里的三维选择预览。图纸及编辑内容随 .s33d 保存；导出文件用于交换与打印。

### 多孔草图区域选择（2026-11-09）

结束草图后，双击需要的材料区域；内部孔洞保持镂空。Objects 列表切换或追加其它对象、修改草图轮廓或平面后，原区域选择会清除，请重新双击选择。只有一个封闭区域时仍可直接使用拉伸。

轮廓相交时按实际交点划分区域。伸入区域但未围成面的枝线，以及仅连接两个闭合圈的线段，不作为材料边界；这些线仍保留在草图中。真正分隔材料的闭合边界仍参与选区。

若区域边界重叠、自相交或孔洞接触，无法通过几何验证时保留轮廓并显示提示。属性栏会持续显示错误，可展开“区域验证详情”查看原因；短暂提示消失后仍可查看。拉伸、切除、旋转及文字/齿轮/螺纹封盖停止该次生成，不提交缺面结果。修正轮廓后重新选择即可。

## 启动、后台加载与圆柱直径编辑（2026-11-10）

启动页为无边框工程图，首选 768×1024，小屏按比例缩小以适应当前显示器工作区。进入工作区后恢复正常边框和缩放，首选 1440×900 客户区，结合工作区、窗口边框及当前 DPI 限制尺寸；空间不足时允许常规 900×600 最小尺寸进一步缩小。字体、偏好和图像在后台读取，图像按原比例完整显示。启动图至少显示 2 秒；通过命令行或“打开方式”加载工程时，若加载超过 2 秒则继续保留，直到加载完成或取消。后台准备和加载在这段时间内照常进行。

打开 .s33d 工程、导入网格和 STEP/IGES 时显示可取消的进度提示。工程和 STEP 的文件读取阶段显示真实字节进度；几何恢复、CAD 重建和网格解析没有可靠百分比时显示阶段文字与等待动画。取消或失败不会提交后台结果；取消不可中断的内核调用后，后台线程可能仍会完成计算，但结果会被丢弃。请等待操作结束或取消后再操作，重复点击不会创建第二个任务。

双击选中可识别的完整圆柱外壁或内孔壁，在属性中修改“直径”并点“应用”。尺寸使用当前显示单位，内部仍为毫米；支持斜轴柱面。支持原生参数圆柱、经认证的草图 Extrude/Pocket 完整圆柱壁及精确实体。草图拉伸的分段实体先验证并转换，再按实际多边形弦边界改径，结果保存为精确直接编辑实体；不修改原共享草图。操作保留对象 ID 和材质；参数圆柱保留原参数特征，可一步撤销/重做。活动下游特征可能要求先编辑源参数；已消耗的 Pocket 孔口草图保留来源记录。若新直径会分裂实体、与其他柱面相交或无法保留完整壁面，操作会拒绝。独立导入的原始网格柱面仍只读。

展开“螺纹生成”时，参数区采用双列，按可见空间及底部控件实际高度尽量展开，放不下时独立滚动；视图控制折叠，历史区缩小，warning、修正和“生成螺纹”保留在参数区下方。孔径 / 毛坯与指定规格不符时可点“按公称直径修正”：保留指定公称直径和全部螺纹、打印参数，实际调整孔径 / 毛坯。底孔直径为公称直径减去两倍牙深；外柱毛坯直径为公称直径加上螺纹长度乘直径锥度。成功后保持修正后的柱面选中，可按原指定规格生成螺纹。修正可一步撤销，生成是独立一步。支持参数圆柱、经认证的草图 Extrude/Pocket 柱面及精确实体；独立导入的原始网格仍只读。分段转换须通过实体认证，目前最多处理 100,000 个三角形；参数无效、几何干涉或存在下游依赖时可能拒绝修正，并保留原模型。

草图拉伸内孔操作顺序：双击孔侧壁 → 展开螺纹生成 → 设定需要的公称直径、牙深及长度 → 按警告点击“按公称直径修正” → 验证通过后点击“生成螺纹”。打印 suggest 仅更新参数；若用了打印建议，先完成建议和参数确认，再 Correct。不要选孔口的草图填充面。完整步骤及支持边界见随附的 ThreadPrinting.md《螺纹打印建议》。

只加工部分长度时，未加工的完整柱面段仍可双击单独选中并继续生成螺纹；中间加工后，上下剩余段分别保留。再次生成时，“起始偏移”从当前选中剩余段的起点计算。保存重开和撤销/重做保留这些段；带有螺纹生成记录的既有工程会根据实际网格重新验证并恢复未加工段。

## 小窗口与显示缩放（2026-11-11）

首次使用指引的正文可滚动，顶部关闭、“不再显示”和“知道了”保持可用。齿轮、表面纹理、轮胎和轮毂生成器的参数与预览区域可滚动，验证信息及生成/应用按钮保留在下方；展开“位置”后，在参数区滚动即可到达后续输入。螺纹参数区同样与 warning、修正、生成分开滚动；保存预设使用独立窗口。调整窗口大小或字号后会重新分配空间。表面纹理预览线不会画出预览框。

Windows 按当前显示器工作区和 DPI 定位，计入任务栏和正常窗口边框，再根据系统返回的实际尺寸修正；不修改系统显示设置。现有自动化覆盖布局及输入，跨不同 DPI 显示器拖动、4K 字体清晰度和 GPU 显示仍需原生屏幕验收。


### 使用已有 Agent 进行照片建模

由 Agent 看照片并理解结构，再调用 S33D 建模，读取原生模型图进行对照和修正。

1. 打开 S33D，在 Settings > Agent Connect（设置 > Agent 连接）启用本机控制并点击 Test Connection（测试连接）。
2. 在 Codex 一栏点击 Register / Update（注册 / 更新），重新打开 Codex；首次连接或安装位置变化后执行此步。
3. 在同一电脑的 Codex 聊天中直接上传照片，说明尺寸、建模要求和 `.s33d` 保存位置。
4. Agent 使用 S33D 建模、对照模型图并修正，保存可编辑工程；后续可在同一聊天中继续修改。

无需先把照片导入 S33D，也无需手动安装 skill、Python 或开发环境。“复制建模提示”在未导入照片时也可用。需要照片随工程保存，或希望通过 S33D 向 Agent 提供参考图时，可选“导入参考照片”；仅导入的照片会嵌入工程。详见 [完整操作、示例和限制](PhotoToModel.md)。


### 工作区辅助显示与最近工程（2026-11-19）

工作区右上角的“网格与 RGB 辅助轴”开关同步显示或隐藏辅助网格及红绿蓝参考轴线；View（视图）菜单中的“显示网格和 RGB 辅助轴”与它联动。Settings > Re-enable all hidden tips（设置 > 重新启用所有隐藏提示）也会恢复两者。此操作只改变显示，不改变模型、吸附或右下角方向指示器。显示状态随工程保存。

File > Open Recent（文件 > 最近打开）保留最近成功打开或保存的最多十个工程，新近使用的排在前面。悬停工程名称可查看完整路径，点击直接打开；当前工程未保存时，仍可选择保存、不保存或取消。列表保存在本机偏好中，重启后保留。文件丢失或无效时保留当前工程与列表；文件移动后可通过“打开项目”重新选择新位置。
