# Wheel Rim Generator plug-in

This optional built-in plug-in creates a closed, editable wheel rim. Diameter,
width, rim thickness, hub, center bore, spoke width, bolt pattern, and position
remain parametric. Styles include Five Spoke, Six Spoke, Split Five Spoke, and
Multi-Spoke.

Enable it from **Plug-ins > Wheel Rim Generator**. Select a generated wheel rim
and reopen the plug-in to update it without changing its Object identity.
