# Tire Generator plug-in

This optional built-in plug-in creates a closed, editable tire from its outer
diameter, rim diameter, section width, tread depth, and tread-repeat count.
Available tread families are Highway Rib, Block, Chevron, and All-Terrain.

Enable it from **Plug-ins > Tire Generator**. Generated tires are ordinary
solid Objects with a rubber material. Select a generated tire and reopen the
plug-in to update it without changing its Object identity.
