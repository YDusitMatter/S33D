# Screw Generator / 螺钉生成器

Built-in S33D plug-in, MPL-2.0. Enable under Plug-ins, then expand its toolbar beneath the menu bar. Creates editable hex, socket cap, countersunk, thumb screws and studs with optional modeled threads. Metric M3–M12, custom dimensions and Print coarse 12 x 2 presets are available. Generate creates one undoable solid; select it later to Update selected or Create copy.

在“插件”中启用，从菜单栏下方工具栏展开。支持六角、内六角圆柱头、沉头、手拧螺钉和螺柱，提供 M3–M12、自定义、打印粗牙预设。选中结果可更新参数或新建副本。径向间隙为单件数值，请先打印配合试件。

See [usage and dimensional references](../../Docs/FastenerGenerators.md). Outputs are sampled mesh solids; nominal presets are not manufacturing tolerance/strength certification.
