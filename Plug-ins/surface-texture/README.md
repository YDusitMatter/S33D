# Surface Texture plug-in

This optional built-in plug-in cuts common knurl patterns into a selected
planar face or the continuous side of a parametric cylinder. Straight, left
diagonal, right diagonal, and diamond patterns expose pitch, groove width,
depth, angle, and edge-margin controls.

Enable it from **Plug-ins > Surface Texture**, select a supported surface, and
open the plug-in. S33D preserves the source Object as a hidden dependency and
creates an editable result Object. Select that result and reopen the plug-in
to update its parameters without changing its Object identity.
