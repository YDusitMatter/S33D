# Nut Generator / 螺帽生成器

Built-in S33D plug-in, MPL-2.0. Enable under Plug-ins, then expand its toolbar beneath the menu bar. Creates editable hex, square, round and flange nuts with through bores and optional modeled threads. Metric M3–M12, custom dimensions and Print coarse 12 x 2 presets are available. Generate creates one undoable solid; select it later to Update selected or Create copy.

在“插件”中启用，从菜单栏下方工具栏展开。支持六角、方形、圆形和法兰螺帽，提供 M3–M12、自定义和打印粗牙预设。底孔贯通，两端带入口倒角；选中结果可更新参数或新建副本。与螺钉保持相同直径、螺距和旋向，先打印短配合试件。

See [usage and dimensional references](../../Docs/FastenerGenerators.md). Outputs are sampled mesh solids; nominal presets are not manufacturing tolerance/strength certification.
