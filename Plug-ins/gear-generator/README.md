# Gear Generator plug-in

This optional built-in plug-in creates parametric involute gears directly in
S33D. It supports spur, helical, bevel, and internal gears, including module,
tooth count, pressure angle, face width, bore, backlash, and type-specific
parameters.

Enable it from **Plug-ins > Gear Generator**. Generated gears are ordinary
solid Objects and retain their parameters: select a generated gear and reopen
the plug-in to update it without changing its Object identity.
