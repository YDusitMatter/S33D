S33D Alpha Preview
作者 / 发行者：YDZM

这是适用于 Windows x64 的 Alpha Preview 预览版本。使用前请为重要工程保留独立备份。
此安装包的安装界面为简体中文。首次启动、尚未保存语言偏好时，主程序默认简体中文。
已有用户语言设置会保留；在程序设置中仍可随时切换中英文。

安装程序为当前用户安装，默认目录：
  %LOCALAPPDATA%\Programs\S33D Alpha Preview
英文版与中文版属于同一个普通安装渠道，可在原位置互相升级，不会并存成两个程序。

可创建开始菜单快捷方式，并可选择创建桌面快捷方式。
安装后不会自动启动程序、注册 Agent、向其它应用安装 skill 或修改文件关联。
更新前请保存工程并关闭 S33D 及连接它的 Agent。Agent 可稍后在程序设置中连接。

卸载只移除已安装程序及快捷方式，保留工程、个人设置和外部 Agent 注册。
如需移除外部 Agent 注册，请在卸载前使用程序设置中的相应功能。

主程序、安装器、快捷方式采用已批准的铁核桃图标。中英文手册位于 Docs。
