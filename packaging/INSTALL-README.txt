S33D Alpha Preview
Author / publisher: YDZM

This is an Alpha Preview for Windows x64. Save a separate copy of valuable
projects before opening them in a preview build. See Docs for the English and
Simplified Chinese user manuals. The interface language is selected in S33D.

The installer and application use the approved transparent iron-walnut artwork,
with silver S3 pipes and leaves, copper 3D lettering, a cracked shell and roots.

Setup installs for the current user, normally in:
  %LOCALAPPDATA%\Programs\S33D Alpha Preview

Setup creates a Start menu shortcut and offers an optional desktop shortcut.
It does not start S33D, register an Agent, install an Agent skill in another
application, or change file associations. Close S33D and its Agent bridge
before updating. Agent registration is available later in S33D Settings.

Uninstall removes the installed application and its shortcuts. It leaves your
projects, %LOCALAPPDATA%\S33D settings, and external Agent registrations intact.
If you want to remove an Agent registration, use S33D Settings before uninstall.
